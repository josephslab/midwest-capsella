# midwest-capsella

Analysis pipeline, scripts, and data for investigating phenotypic variation and genomic diversity ($\pi$ at 4-fold degenerate sites and principal component structure) across Midwestern urban populations of *Capsella bursa-pastoris* (Detroit, Grand Rapids, Kalamazoo, Madison, and Milwaukee).

---

## Repository Structure

```text
midwest-capsella/
├── data/       # Phenotypic measurements and genomic diversity (pixy) files
├── scripts/    # Shell, R, and R Markdown scripts for data processing, modeling, and figures
├── figures/    # Generated publication figures and diagnostic plots
└── LICENSE
```

## `data/` Directory

| File | Description |
| :--- | :--- |
| **`1stHarvRformatedSeeds_Nov27.csv`** | Raw first-harvest common garden phenotypic dataset ($n = 504$ individuals). Contains plant/genotype identifiers (`F2_Plant_ID`, `Genotype`, `Unique.ID`, `Parent.ID`, `F2_Rep`), experimental metadata (`GrowingConditions` [`GC` = growth chamber, `GH` = greenhouse], `ParentGrowingConditions`, `ParentBlock`, `YearParentGrown`), geographic origins (`City`, `Population`, `Individual`, `Lat`, `Long`), phenological dates, and measured traits including rosette diameter (`Rosette_D`), leaf lobing (`Lobed_level`), flowering and harvest heights (`Height_Flower`, `Height_Harvest`), fruit and seed counts (`N_Fruits`, `Seed_count`), branch counts (`Rosette_branches`, `Cauline_branches`), developmental timing (`DaysFridgetoGerm`, `DaysGermToBolt`, `DaysPlantToBolt`, `DaysBoltToFlower`), and pre-scaled morphological variables (`HavHeight_Scaled`, `Rosbranches_Scaled`, `Caulibranches_Scaled`). |
| **`midwest_pixy_pops.txt`** | Two-column, tab-delimited population assignment file mapping 32 sequenced sample IDs to their respective Midwestern city population codes (`D` = Detroit, `GR` = Grand Rapids, `Kal` = Kalamazoo, `Mad` = Madison, `Mil` = Milwaukee) for use with `pixy`. |
| **`1-based_4-fold_sites_CBP_allSites_msu_maf.txt`** | Two-column, tab-delimited genomic coordinates file (`scaffold`, `1-based_position`) listing 335,380 4-fold degenerate sites across *C. bursa-pastoris* scaffolds (`jlSCF_*`). Passed to `pixy --sites_file` to restrict nucleotide diversity calculations to putatively neutral 4-fold degenerate sites. |
| **`Midwest_4-fold_10kb_pi.txt`** | Output table generated by `pixy` (`scripts/4fold_windows_pi.sh`) containing nucleotide diversity ($\pi$) estimates across 10 kb genomic windows for each of the five Midwestern populations (`D`, `GR`, `Kal`, `Mad`, `Mil`). Columns: `pop`, `chromosome`, `window_pos_1`, `window_pos_2`, `avg_pi`, `no_sites`, `count_diffs`, `count_comparisons`, and `count_missing`. |

*(Note: Running `scripts/process-phenotype-data.Rmd` or `scripts/Linear-mixed-effect-model.R` also writes an intermediate file `data/FinalDataAll_Nov27.csv` with computed `Fecundity` and `BushyScore` columns.)*

## `scripts/` Directory

### Phenotypic Data Processing & Mixed-Effects Modeling

* **`process-phenotype-data.Rmd`** (and rendered **`process-phenotype-data.md`**)
  Streamlined, reproducible R Markdown workflow for the phenotypic analyses:
  1. Loads `data/1stHarvRformatedSeeds_Nov27.csv` and calculates composite traits (`Fecundity = (Seed_count / 5) * N_Fruits` and `BushyScore = (Rosbranches_Scaled - Caulibranches_Scaled - HavHeight_Scaled) / 2`).
  2. Filters for Midwest growth chamber (`GC`) individuals and removes within-city univariate outliers ($> 3\text{ SD}$ from the city mean).
  3. Tests for homogeneity of variance across cities and parental growing conditions using Levene's test with Benjamini-Hochberg FDR adjustment.
  4. Fits generalized linear mixed models (`glmmTMB`) testing for city effects (`ParentGrowingConditions + City + F2_Rep + (1 | Genotype)`) using Gaussian or log-link Gamma families (with dispersion models where appropriate), evaluates likelihood ratio tests against null models, and checks residuals with `DHARMa`.
  5. Generates multi-panel variance boxplots (`figures/figure1_variance_boxplots.png`) and least-squares means (`emmeans`) plots (`figures/figure2_lsmeans_with_points.png`), and applies FDR corrections across model p-values.

* **`figure1.R`**
  Standalone R script to reproduce **Figure 1** (`figures/figure1_variance_boxplots.png`): a 4-panel boxplot with jittered raw data points showing phenotypic variance across Midwestern cities for bolting time (`DaysPlantToBolt`), flowering time (`FlowerTime`), height at flowering (`Height_Flower`), and height at harvest (`Height_Harvest`).

* **`figure2.R`**
  Standalone R script to reproduce **Figure 2** (`figures/figure2_lsmeans_with_points.png`): fits `glmmTMB` mixed-effects models and plots estimated marginal means (`emmeans`) $\pm$ SE overlaid on raw jittered data points across cities for bolting time (`DaysPlantToBolt`), rosette diameter (`Rosette_D`), flowering time (`FlowerTime`), and `Fecundity`.

* **`Linear-mixed-effect-model.R`**
  Original exploratory and comprehensive R script documenting the full model selection workflow, distribution diagnostics, trait transformations, Levene's tests, `lme4`/`nlme`/`glmmTMB` comparisons, and plot generation that were subsequently consolidated into `process-phenotype-data.Rmd`, `figure1.R`, and `figure2.R`.

### Genomic Diversity ($\pi$) & PCA Clustering

* **`4fold_windows_pi.sh`**
  SLURM batch script (`MidwestPiWindows`) that runs `pixy` (v1.2+) to calculate nucleotide diversity ($\pi$) in 10 kb windows across 4-fold degenerate sites (`data/1-based_4-fold_sites_CBP_allSites_msu_maf.txt`) for the five Midwestern populations defined in `data/midwest_pixy_pops.txt`, producing `data/Midwest_4-fold_10kb_pi.txt`.

* **`chrissy_pi_4fold.R`**
  R script analyzing the windowed 4-fold degenerate $\pi$ output (`data/Midwest_4-fold_10kb_pi.txt`):
  1. Computes genome-wide weighted average $\pi$ (`sum(count_diffs) / sum(count_comparisons)`) and window summaries per city.
  2. Performs 1,000-replicate bootstrap resampling across genomic windows to calculate 95% confidence intervals for both mean and median $\pi$ per city.
  3. Generates city-level $\pi$ point-and-error-bar plots (`figures/mean_pi_ci.jpeg`) and bootstrap distribution histograms (`figures/*_bootstrap_pi*.jpeg`).
  4. Runs a 10,000-iteration permutation ANOVA and pairwise permutation t-tests (`RVAideMemoire::pairwise.perm.t.test`) to test for significant differences in nucleotide diversity among cities.

* **`PCA-plot-Fig5.R`**
  R script to plot genomic Principal Component Analysis (PCA) eigenvectors (PC1 vs. PC2) colored and shaped by Midwestern city (excluding a Grand Rapids outlier), corresponding to Figure 5 in the manuscript. *(Note: references an external eigenvector CSV path that should be updated to local paths before running.)*

* **`Phenotypic-clusters-on-PCA.R`**
  R script that summarizes genotype-level means for measured phenotypes, merges them with genomic PCA cluster assignments (`PCsCAT`: Cluster 1 vs. Cluster 2), generates multi-panel point/error-bar plots comparing phenotypic traits across genotypes and PCA clusters, and conducts Kruskal-Wallis tests (`kruskal.test`) to test whether any phenotypic traits differ significantly between genomic PCA clusters. *(Note: references external CSV paths for PCA eigenvectors/cluster assignments.)*

* **`ReadMe.txt`**
  Brief legacy reference note mapping original manuscript figure numbers (Figures 2–7) to earlier working drafts of the R scripts.
